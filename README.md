# FNT Local Docs

Windows-first, local-first desktop software for PDF conversion, OCR, document organization, batch processing, and result previewing.

## Product principles

- Process files locally by default; do not upload user documents.
- Make common conversions fast and transparent.
- Show a per-file progress, result, and actionable failure reason.
- Treat complex PDF-to-Office conversions as best-effort exports.

## Planned first milestone

- Drag-and-drop conversion queue with per-file progress and save actions.
- Image-to-PDF conversion with reorderable images.
- PDF merge, split, rotation, and password protection.
- PDF/image preview with a responsive side drawer or bottom panel.
- Local conversion history.
