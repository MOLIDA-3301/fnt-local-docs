# FNT Local Docs 功能与验收矩阵

本文档是桌面版的正式产品范围。状态只反映仓库中已经可以实际执行并通过测试的能力；界面占位不算完成。

状态含义：`已实现`、`开发中`、`待实现`、`后续版本`。

## 1. 转成 PDF

| 能力 | 状态 | 验收要求 |
| --- | --- | --- |
| 图片（JPG、PNG、WebP、BMP、TIFF）→ PDF | 已实现 | 严格按队列顺序输出；执行像素限制 |
| 多张图片 → 一个 PDF | 已实现 | 支持上移、下移、移除；页序等于队列顺序 |
| TXT / Markdown → PDF | 已实现 | 内置离线引擎，支持中英文分页 |
| DOCX → PDF | 已实现 | 调用本机 LibreOffice；未安装时给出明确安装提示 |
| PowerPoint / PPTX → PDF | 已实现 | 同上 |
| Excel / XLSX / CSV → PDF | 已实现 | 同上 |
| HTML 文件 → PDF | 已实现 | 第一版调用 LibreOffice；后续评估独立 HTML 渲染器 |
| 多种文件合并为一个 PDF | 已实现 | 先逐项转换，再严格按队列顺序合并；失败信息包含对应文件名 |

## 2. 从 PDF 导出

| 能力 | 状态 | 验收要求 |
| --- | --- | --- |
| PDF → TXT / Markdown | 已实现 | 电子文字提取；扫描件明确提示 OCR |
| PDF → 图片 | 已实现 | 可选 DPI，逐页输出 PNG 并打包 ZIP |
| PDF → Word | 开发中 | Win10/11 已接入 pdf2docx 电子 PDF 版式还原；扫描件已自动 OCR；Win7 文字型回退待补 |
| PDF → Excel | 开发中 | 已接入坐标文字、扫描页 OCR、有框/无框/多表、低置信度批注和 Raw 回退；跨页续接与合并单元格仍需加强 |
| PDF → PPT | 已实现 | 每页 PDF 对应一页图片型幻灯片，优先保证视觉一致，不承诺元素可编辑 |

## 3. OCR 与扫描文档

图片和扫描 PDF 已可离线导出 TXT、Markdown、Word，并可生成带隐藏文字层的可搜索 PDF；中英文模型随转换器打包，低置信度文字会被标记。对比度归一化已接入，自动倾斜校正和裁边仍在开发。当前状态：`开发中`。

## 4. PDF 整理与安全

| 能力 | 状态 |
| --- | --- |
| PDF 合并 | 已实现 |
| 按单页或每 N 页拆分并打包 ZIP | 已实现 |
| AES-256 加密、凭原密码解密 | 已实现 |
| 提取指定页、调整/旋转/删除页面 | 已实现（通过页码顺序表达提取、重排和删除） |

## 5. 批量、保存和历史

已支持文件/文件夹选择与拖入、队列上移/下移、逐文件状态与失败原因、批次暂停/继续/取消、失败重试、输出目录、命名规则、冲突策略、结果打开和最多 500 条本地历史。当前进度以文件级阶段进度为主；正在运行的单文件会完成后再响应取消或暂停，后续再增加可中断的页级进度。

## 6. 预览

已在宽窗口使用右侧抽屉、窄窗口自动切换底部面板，可预览图片、PDF、文本/Markdown、音频和视频。音视频是否可播放取决于 Windows WebView2 已有的系统编解码器；FFmpeg 只用于后续扩展媒体兼容，不进入第一版文档转换核心，AVS3 不纳入当前范围。

## 7. 资源保护

- 单图最大 50MP，任一边最大 16,384px：已实现。
- 图片合并 PDF 总计最大 100MP：已实现。
- 单批输入最大 2GB：已在通用“转成 PDF”入口实现。
- PDF 和 OCR 不设页数硬上限，但必须逐页/分块处理，并加入内存、磁盘和耗时保护：待实现。
- 单文件失败不终止整个批次，并保存对应失败原因：已实现。

## 8. 平台原则

- Windows 10/11 为主要目标；Windows 7 仅提供基础兼容能力。
- 默认本地离线，无账号、无云端存储、无持续服务器成本。
- PDF 与 OCR 引擎及中英文资源随软件提供。
- LibreOffice 是 Office/CSV/HTML 转 PDF 的可选外部引擎；软件负责检测并引导安装。
- AI 翻译不属于基础功能，未来只作为用户主动启用的增强项。
